Review a procurement package

Levels the bids, checks each bidder's product against the spec, forecasts delivery for each award option and drafts the vendor follow-ups. It recommends an award only when that is safe; otherwise it lays out the options for you.

Bidders

For each bidder: their bid, and (if you have it) their product submittal to check against the spec.

About 40-60 model calls on the free tier; a few minutes.

Check a submittal against the spec

One answer per requirement (complies, deviates, missing or unclear), each with the spec paragraph and the datasheet page quoted word for word. Anything the agent is not sure about goes to you.

About 15-25 model calls on the free tier.

Level competing bids

Lines up every bid against the bid form's scope, prices the gaps with the owner's allowances (or the bidder's own alternate), flags risky commercial terms and lead times, and ranks the leveled totals.

Delivery risk for long-lead equipment

For every item group in the equipment schedule: likely arrival dates (P10 / P50 / P90), the chance of missing the need date, the latest order date for an 80% on-time chance, and what to do. Calculated in code from cited lead-time sources, so no model calls and no tokens.
